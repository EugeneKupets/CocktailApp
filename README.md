# 🍸 CocktailApp

**CocktailApp** — це сучасний Android-додаток для справжніх поціновувачів барної культури. Програма дозволяє досліджувати тисячі рецептів коктейлів, фільтрувати їх за інгредієнтами та створювати власну цифрову колекцію найкращих напоїв.

## 🚀 Основна мета
Проект створений для демонстрації поєднання мобільного клієнта на Jetpack Compose з повноцінним бекендом, що дозволяє користувачу мати доступ до своїх даних з будь-якого пристрою.

## ✨ Ключові можливості

*   **Авторизація через Google:** Безпечний та швидкий вхід за допомогою Google Identity Services. Ваш профіль та список улюблених напоїв прив'язані до вашого Google-аккаунта.
*   **Дослідження коктейлів:** 
    *   Перегляд списків алкогольних та безалкогольних напоїв.
    *   Детальна інформація про кожен коктейль: інгредієнти, пропорції та покрокова інструкція приготування.
*   **Розумний пошук та фільтрація:**
    *   Пошук коктейлів за назвою в реальному часі.
    *   Потужний фільтр за інгредієнтами — знайдіть, що можна приготувати з того, що вже є у вашому барі.
*   **Система "Улюблених" (Favorites):**
    *   Можливість додавати будь-який коктейль до персонального списку одним натисканням на "серце".
    *   **Синхронізація з хмарою:** Ваші вподобання не зберігаються лише на телефоні — вони миттєво відправляються на бекенд-сервер.
    *   Окремий екран "Favorites" для швидкого доступу до ваших обраних рецептів.

## 🛠 Технологічний стек

### **Frontend (Android):**
*   **Kotlin:** Основна мова розробки.
*   **Jetpack Compose:** Сучасний декларативний UI.
*   **Retrofit 2:** Для взаємодії з REST API (TheCocktailDB та власний бекенд).
*   **Kotlinx Serialization:** Для парсингу JSON даних.
*   **Glide (Compose support):** Для швидкого завантаження та кешування зображень коктейлів.
*   **Navigation Compose:** Для плавної навігації між екранами.
*   **Google Credential Manager:** Для реалізації входу через Google.

### **Backend:**
*   **Node.js / Express:** Основний серверний фреймворк.
*   **MongoDB:** Для надійного зберігання даних користувачів та їхніх взаємодій.
*   **Railway:** Платформа для хостингу бази даних та серверної частини.

## 📦 Як запустити проект

1.  **Клонуйте репозиторій:**
    ```bash
    git clone https://github.com/your-username/CocktailApp.git
    ```
2.  **Налаштування API:**
    У файлі `BackendApi.kt` замініть `BASE_URL` на посилання на ваш розгорнутий сервер на Railway.
3.  **Google Auth:**
    Налаштуйте `serverClientId` у класі `GoogleAuthClient.kt`, отримавши його з Google Cloud Console.
4.  **Запуск:**
    Відкрийте проект в Android Studio та запустіть на емуляторі або реальному пристрої.

## 📱 Екрани додатку
*   **Головний екран:** Список напоїв з можливістю швидкого додавання в улюблене.
*   **Деталі коктейлю:** Повна рецептура та візуалізація інгредієнтів.
*   **Профіль:** Керування аккаунтом та перехід до списку обраних напоїв.
*   **Фільтр:** Список інгредієнтів для точного підбору рецептів.
